Run Roblox natively on Linux

TuxBlox runs Roblox Studio on Linux. You get the real Studio, the same one Windows users get, not a copy or a lookalike. Everything it needs comes with it, so there is nothing else to install. TuxBlox is free, open source, and in active development.

Features

Works out of the box

Installation, updates and graphics setup are handled by the launcher. There are no launch options to supply or no prefix to maintain, TuxBlox handles everything for you.

Native performance

No virtual machine sits between Roblox and your hardware. Studio starts quickly, and the GPU is driven directly rather than through an emulation layer.

How it works

Roblox only releases Studio for Windows. There is no Linux version of it, and that is the gap TuxBlox fills. Whenever Studio asks for something it would normally get from Windows, like a window to draw in or a file to open, TuxBlox answers instead, and Studio carries on as though it were running on Windows.

There is no copy of Windows involved anywhere, and nothing is being imitated in software. Studio's own code runs directly on your processor at full speed, so you do not pay the performance and memory cost that a virtual machine or an emulator would ask of you. The Studio on your disk stays exactly the one Roblox published, down to the last byte.

TuxBlox is built for Roblox and nothing else. That sounds like a limitation, and it is the reason things work properly: when something misbehaves it gets fixed at the cause, instead of being worked around with a setting. Tools that have to run thousands of different programs cannot afford to do that.

No Windows installation No second operating system, no disk image, and no Windows licence to buy.
Roblox stays untouched The Studio files are exactly the ones Roblox publishes. TuxBlox does not patch them or repackage them.
Nothing set aside up front Memory and graphics are used as they are needed, the same as any other program on your computer.

Common questions

What are the requirements?

Most current Linux installations already satisfy these requirements.

  • KernelLinux 6.7 or newer
  • Processorx86-64 with SSE3
  • Memory4 GB, 8 GB comfortable
  • Disk space4 GB free, 6 GB comfortable
  • NVIDIA graphicsProprietary driver 418.49.04 or newer
  • AMD graphicsMesa 17.0 or newer
Will this get my account banned?

For Studio, probably not. Roblox has allowed the usage of Roblox Studio on Linux for a long while now, however Roblox may still take action on your account at any time.

For Player, account safety will not be guaranteed. Player is not part of a release yet. When it is, Roblox still will not support Linux, and its anti-cheat may flag your account at any point. Your account might be banned or terminated, and that risk will be yours to take.

Check our documentation for more information about this.

Which Roblox apps are supported?

Roblox Studio is what TuxBlox runs today. It is the app the whole project is built around, and it should run correctly.

Roblox Player is still in progress. It is not part of a TuxBlox release yet, it is the next thing being worked on, and there is no date to give for it.

Does it require root?

No. TuxBlox installs and runs entirely as an unprivileged user. Root is not required at any point, and you will not be asked for a password.
